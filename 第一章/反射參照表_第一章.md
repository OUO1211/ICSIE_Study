# 反射參照表｜第一章：矩陣

> 協議：看到題目特徵 → 直接映射原子動作。禁止推導過程，只輸出索引路徑。

| 看到 (Signal / 題目特徵) | 想到 (Mapping / 原子反射動作) | 來源筆記 |
| :--- | :--- | :--- |
| $AB \neq BA$，問乘法順序 | 矩陣乘法不可交換；$(AB)^{-1} = B^{-1}A^{-1}$，$(AB)^T = B^T A^T$，$(AB)^H = B^H A^H$，反序法則一律適用 | [[矩陣乘法]]、[[轉置矩陣]]、[[共軛轉置矩陣]]、[[可逆矩陣]] |
| $AB = O$，問 $A$ 或 $B$ 是否為零矩陣 | 零因子存在，$AB = O$ 不代表 $A = O$ 或 $B = O$ | [[矩陣乘法]] |
| $AB = AC$，問能否消去 $A$ | 只有 $A$ 可逆時才能消去；否則不可 | [[矩陣乘法]]、[[可逆矩陣]] |
| 出現 $AA^T$ 或 $A^T A$ | 恆為對稱矩陣；$\text{tr}(A^T A) =$ 各元素的平方和 | [[轉置矩陣]]、[[對稱矩陣與斜對稱矩陣]]、[[跡數Trace]] |
| 求 $A^T$ 或 $A^H$ 的性質 | $(AB)^T = B^T A^T$；$(AB)^H = B^H A^H$；$(kA)^H = \bar{k}A^H$（純量要取共軛） | [[轉置矩陣]]、[[共軛轉置矩陣]] |
| $A^T = A$ | $A$ 為對稱矩陣；$A$ 可逆則 $A^{-1}$ 亦對稱；特徵值均為實數（進階） | [[對稱矩陣與斜對稱矩陣]]、[[可逆矩陣]] |
| $A^T = -A$ | $A$ 為斜對稱矩陣；對角項**必為** $0$ | [[對稱矩陣與斜對稱矩陣]] |
| 任意方陣 $A$，問對稱/斜對稱分解 | $A = \frac{A+A^T}{2} + \frac{A-A^T}{2}$（對稱部分 + 斜對稱部分） | [[對稱矩陣與斜對稱矩陣]] |
| $A^H = A$（複數矩陣） | $A$ 為 Hermitian；對角項**必為實數**；特徵值均為實數 | [[Hermitian矩陣]] |
| $A^H = -A$（複數矩陣） | $A$ 為斜 Hermitian | [[Hermitian矩陣]] |
| 出現 $\text{tr}(AB)$ 或 $\text{tr}(BA)$ | $\text{tr}(AB) = \text{tr}(BA)$（循環置換）；但 $\text{tr}(AB) \neq \text{tr}(A)\text{tr}(B)$ | [[跡數Trace]] |
| 問是否存在 $AB - BA = I$ | 利用 $\text{tr}(AB-BA) = 0 \neq n$，直接矛盾否定 | [[跡數Trace]] |
| $A$ 為冪零且 $A^k = O$，$\text{tr}(A)$ 的值 | $\text{tr}(A) = 0$（因特徵值全為 $0$） | [[冪零矩陣]]、[[跡數Trace]] |
| $AB = I$（方陣），問是否 $BA = I$ | 方陣只需驗一側：$AB = I \Leftrightarrow BA = I$ | [[可逆矩陣]] |
| 求 $(AB)^{-1}$、$(A^T)^{-1}$、$(A^H)^{-1}$、$(kA)^{-1}$、$(A^k)^{-1}$ | 反矩陣七性質：$(AB)^{-1}=B^{-1}A^{-1}$；$(A^T)^{-1}=(A^{-1})^T$；$(A^H)^{-1}=(A^{-1})^H$；$(kA)^{-1}=\frac{1}{k}A^{-1}$；$(A^k)^{-1}=(A^{-1})^k$ | [[可逆矩陣]] |
| $2 \times 2$ 矩陣 $A = \begin{bmatrix}a&b\\c&d\end{bmatrix}$，求反矩陣 | $A^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$（$ad-bc \neq 0$） | [[可逆矩陣]] |
| 分塊三角矩陣，求反矩陣 | 套用分塊三角公式：對角塊各自取逆，非對角塊用 $-A_{11}^{-1}A_{12}A_{22}^{-1}$ 或 $-A_{22}^{-1}A_{21}A_{11}^{-1}$ | [[分塊矩陣的反矩陣]] |
| $\text{diag}(c_1,\ldots,c_n)$，求反矩陣 | $\text{diag}(c_1^{-1},\ldots,c_n^{-1})$（每個對角項直接取倒數） | [[對角矩陣與單位矩陣]]、[[分塊矩陣的反矩陣]] |
| $A^k = O$（冪零），求 $(I-A)^{-1}$ 或 $(I+A)^{-1}$ | $(I-A)^{-1} = I+A+A^2+\cdots+A^{k-1}$；$(I+A)^{-1} = I-A+A^2-\cdots+(-A)^{k-1}$（幾何級數展開） | [[冪零矩陣]]、[[矩陣多項式]] |
| $A^2 = A$（冪等矩陣），求 $f(A)$ 或 $A^n$ | 利用 $A^k = A$（$k \geq 1$），代入多項式；$(A+I)^n = I + (2^n-1)A$ | [[矩陣多項式]] |
| 嚴格上（下）三角矩陣 | 必為冪零矩陣（$A^n = O$，$n$ 為矩陣階數） | [[三角矩陣]]、[[冪零矩陣]] |
| 上（下）三角矩陣相乘 | 結果仍為上（下）三角矩陣 | [[三角矩陣]] |
| 上（下）三角矩陣求反矩陣 | 反矩陣仍為上（下）三角矩陣 | [[三角矩陣]] |
| 求反矩陣（一般 $n$ 階方陣） | 高斯-喬登：對 $[A \mid I]$ 做列運算化為 $[I \mid A^{-1}]$ | [[利用列運算求反矩陣]] |
| 做列運算等價於什麼矩陣操作 | 對矩陣**左乘**對應基本列矩陣；$B = PA$（$P$ 為列基本矩陣乘積，即可逆矩陣） | [[基本列運算]] |
| 做行運算等價於什麼矩陣操作 | 對矩陣**右乘**對應基本行矩陣；$B = AQ$ | [[基本行運算]] |
| $A$ 可逆，用基本矩陣表示 | $A$ 可表為若干列基本矩陣（或行基本矩陣）的乘積 | [[基本列運算]]、[[基本行運算]] |
| LU 分解存在的條件 | 各**領導主子行列式**均非零；若某主元為 $0$ 則需改用 PLU 分解 | [[LU分解]]、[[PLU分解]] |
| 解 $Ax = b$，$A$ 已做 LU 分解 | 拆成兩步：先 $Ly = b$（前向代入），再 $Ux = y$（後向代入） | [[LU分解]] |
| LDU 分解，如何從 LU 得到 | 提出 $U$ 的對角項組成 $D$，化 $U$ 為對角 $1$ 的上三角；$A = LDU$ | [[LDU分解]] |
| 主元為 $0$，LU 失效 | 先做列置換（置換矩陣 $P$），得 $PA = LU$；解方程組改解 $LUx = Pb$ | [[PLU分解]] |
| 置換矩陣 $P$ 的反矩陣 | $P^{-1} = P^T$（置換矩陣為正交矩陣） | [[PLU分解]] |
| 求 $\text{rank}(A)$（一般矩陣） | 列運算化為 REF，數 pivot 個數；或列行運算化 PAQ 分解，讀 $r$ | [[秩Rank]]、[[RREF簡化列梯陣]]、[[PAQ分解]] |
| $\text{rank}(A) = \text{rank}([A \mid b])$ 且 $= n$ | 方程組 $Ax = b$ 有**唯一解** | [[秩Rank]] |
| $\text{rank}(A) \neq \text{rank}([A \mid b])$ | 方程組 $Ax = b$ **無解** | [[秩Rank]] |
| $\text{rank}(A) = \text{rank}([A \mid b]) < n$ | 方程組 $Ax = b$ 有**無限多解**，自由變數個數 $= n - \text{rank}(A)$ | [[秩Rank]] |
| $\text{rank}(A) = m$（$m \times n$ 矩陣） | 對任意 $b$，$Ax = b$ 至少有一解（行滿秩） | [[秩Rank]] |
| $A$ 可逆（$n$ 階方陣）的等價條件 | $\text{rank}(A) = n$ $\Leftrightarrow$ RREF 為 $I_n$ $\Leftrightarrow$ $Ax=0$ 只有零解 | [[秩Rank]]、[[RREF簡化列梯陣]]、[[可逆矩陣]] |
| PAQ 分解的結果 | $PAQ = \begin{bmatrix}I_r & O \\ O & O\end{bmatrix}$，其中 $r = \text{rank}(A)$；可用來判斷秩 | [[PAQ分解]] |
| 矩陣 $A$ 的行向量構成 $[v_1\ v_2\ \cdots\ v_n]$，$A$ 可逆 | 行向量線性獨立；可逆矩陣作用保持線性獨立性 | [[可逆矩陣]]、[[矩陣乘法]] |
