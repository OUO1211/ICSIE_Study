# 述詞邏輯的推論規則（Rules of Inference）

## 定義

在[[論證與推論規則|命題邏輯推論規則]]的基礎上，述詞邏輯多了處理量詞（$\forall, \exists$）的四條規則，以及結合 [[p→q的相關命題|modus tollens]] 的全稱版本。

## 核心模型/公式

| 名稱 | 型式 |
|---|---|
| 全稱個例化（universal instantiation / specification） | $\dfrac{\forall x,\ P(x)}{\therefore P(c)}$（$c$ 為論域中任一元素） |
| 全稱通則化（universal generalization） | $\dfrac{\text{對任意 } c,\ P(c)}{\therefore \forall x,\ P(x)}$ |
| 存在個例化（existential instantiation / specification） | $\dfrac{\exists x,\ P(x)}{\therefore P(c)\ \text{for some } c}$ |
| 存在通則化（existential generalization） | $\dfrac{\text{for some } c,\ P(c)}{\therefore \exists x,\ P(x)}$ |
| 全稱性的否定後件（universal modus tollens） | $\dfrac{\forall x[P(x) \rightarrow Q(x)],\ \ \sim Q(a)\ \text{for some } a}{\therefore \sim P(a)}$ |

## 經典考題

**例題（5%）【98成大工科】** Give an argument using rules of inference to show if the conclusion follows from the hypotheses.

**Hypotheses**：
- Everyone in the class has a graphing calculator.
- Everyone who has a graphing calculator understands the trigonometric functions.

**Conclusion**：Ralphie, who is in the class, understands the trigonometric functions.

**解**：論域為班上同學，令 $C(x): x$ 在班上，$G(x): x$ 有繪圖計算機，$T(x): x$ 懂三角函數。原敘述相當於：

$$
\begin{aligned}
&\forall x,\ C(x) \rightarrow G(x) &&\text{敘述 (1)}\\
&\forall x,\ G(x) \rightarrow T(x) &&\text{敘述 (2)}\\
&C(\text{Ralphie}) &&\text{敘述 (3)}\\
&\therefore T(\text{Ralphie}) &&\text{敘述 (4)（待證結論）}
\end{aligned}
$$

推導過程：

1. 由敘述 (1) 與 Rule of Universal Specification，可得 $C(\text{Ralphie}) \rightarrow G(\text{Ralphie})$ ——敘述 (5)
2. 由敘述 (3)、(5) 與 Modus Ponens，可得 $G(\text{Ralphie})$ ——敘述 (6)
3. 由敘述 (2) 與 Rule of Universal Specification，可得 $G(\text{Ralphie}) \rightarrow T(\text{Ralphie})$ ——敘述 (7)
4. 由敘述 (6)、(7) 與 Modus Ponens，可得 $T(\text{Ralphie})$ ——敘述 (4)，得證。

## 多選題防線 (Corner Cases)

- ⚠️ 全稱個例化（universal instantiation）可套用到論域中**任意**元素 $c$；但存在個例化（existential instantiation）只能引入一個**新的、未被使用過**的代表元素 $c$，不能是已經在推導中出現過、帶有其他限制的符號——這是述詞邏輯證明題常出現的隱藏規則。
- ⚠️ 全稱通則化（universal generalization）要求「對任意 $c$」都成立，若 $c$ 是從某個特定假設中取出的（帶有額外限制），不能直接推廣為 $\forall x P(x)$，否則會犯下推論錯誤。
- ⚠️ 解題套路固定：把自然語言轉成 $\forall x[\cdots]$ 形式的前提 → 用 universal specification 代入具體個體 → 用 modus ponens／modus tollens 逐步推出結論，是 [[述詞邏輯的翻譯]] 與本篇推論規則的標準組合拳。
