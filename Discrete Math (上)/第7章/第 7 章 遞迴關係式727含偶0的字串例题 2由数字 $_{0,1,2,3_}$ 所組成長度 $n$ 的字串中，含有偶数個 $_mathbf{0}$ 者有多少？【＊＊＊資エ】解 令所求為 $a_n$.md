第 7 章 遞迴關係式

727



含偶0的字串

例题 2

由数字 $\{0,1,2,3\}$ 所組成長度 $n$ 的字串中，含有偶数個 $\mathbf{0}$ 者有多少？

【＊＊＊資エ】

解 令所求為 $a_n$ ，則一個數字且含偶個 0 ，有 $1,2,3$ 共三種，即 $a_1=3$ ，

而對 $n \geq 2$ ，符合題目敘述的字串可分類計算如下：

若字串第一個數字為 0 ，則後面 $n-1$ 個數含有奇個 0 ，有 $4^{n-1}-a_{n-1}$ 種狀況，

（ ∵ 後 $(n-1)$ 數總共有 $4^{n-1}$ 種字串減此出現偶個 0 的字串數）

若第一個數字不為 0 ，則只需後面 $n-1$ 個數含有偶個 0 ，有 $3 \times a_{n-1}$ 種，

（因為第一個數可能為 $1,2,3$ ）

得遞迴關係式：$a_n=\left\{\begin{array}{ll}4^{n-1}+2 a_{n-1}, & n \geq 2 \\ 3, & n=1\end{array}\right.$ ，

可以特徴多項式法解得 $a_n=\frac{2^n+4^n}{2}, n \geq 1$ ．
