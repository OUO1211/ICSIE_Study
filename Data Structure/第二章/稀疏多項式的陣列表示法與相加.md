## 定義

**稀疏多項式（Sparse Polynomial）的陣列表示法**：一元多項式中非零項通常遠少於總項數（如 $x^{1000}+1$ 只有 2 個非零項），若逐一儲存所有係數會極度浪費空間。因此改用**只儲存非零項**的方式：每個非零項以一筆 $(COEF, EXP)$（係數、指數）記錄表示，並依指數大小排序存放於陣列或串列中。

多變數多項式（如 $A(x,y)$）則將每項擴充為 $(COEF, EXP_x, EXP_y)$ 三元組。

## 核心模型/公式

### 一元多項式相加演算法（合併排序法 / Two-pointer Merge）

設多項式 $A$、$B$ 皆依指數遞減排序存放，`EXP(·)` 取目前項次的指數、`COEF(·)` 取係數、`RED(·)` 將指標移至下一項、`IsZero(·)` 判斷是否已無剩餘項次。相加結果存入 $C$：

```
while (not IsZero(A) and not IsZero(B)) {
    case EXP(A) < EXP(B):
        C = Insert(C, COEF(B), EXP(B));
        B = RED(B);                      /* 取 B 的下一項 */
    case EXP(A) = EXP(B):
        C = Insert(C, COEF(A)+COEF(B), EXP(A));
        A = RED(A);
        B = RED(B);
    case EXP(A) > EXP(B):
        C = Insert(C, COEF(A), EXP(A));
        A = RED(A);
}
while (A 中還有剩餘的項次) {              /* B 已耗盡，A 剩餘項直接搬入 C */
    C = Insert(C, COEF(A), EXP(A));
    A = RED(A);
}
while (B 中還有剩餘的項次) {              /* A 已耗盡，B 剩餘項直接搬入 C */
    C = Insert(C, COEF(B), EXP(B));
    B = RED(B);
}
```

**核心概念**：此演算法與「合併兩個已排序陣列」（Merge，見排序章節）完全同構——同時掃描 $A$、$B$，指數較大者優先搬入結果，指數相同則係數相加，最後把任一方剩餘的項次直接接到結果尾端。

**時間複雜度**：設 $A$ 有 $m$ 項、$B$ 有 $n$ 項，則相加演算法為 $O(m+n)$。

### 多變數多項式的表示法

雙變數多項式 $A(x,y) = 7x^4 + 5x^4y^3 + 6x^3y^2 - 8x^2y + 9xy + 8$ 可表示為一組 $(COEF, EXP_x, EXP_y)$ 三元組：

| COEF | $EXP_x$ | $EXP_y$ |
|---|---|---|
| 7 | 4 | 0 |
| 5 | 4 | 3 |
| 6 | 3 | 2 |
| -8 | 2 | 1 |
| 9 | 1 | 1 |
| 8 | 0 | 0 |

**解題技巧**：多變數多項式的排序基準通常先比較 $EXP_x$，$EXP_x$ 相同時再比較 $EXP_y$（類似 [[二維陣列位址計算RowColumnMajor|Row-major 的排序邏輯]]），常數項（如本例的 $8$）對應 $EXP_x = EXP_y = 0$。
