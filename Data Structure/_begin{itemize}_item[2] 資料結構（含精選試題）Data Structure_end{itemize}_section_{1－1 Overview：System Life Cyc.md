\section*{1－1 Overview：System Life Cycle}

\begin{itemize}

\item[] －．Requirements

\begin{itemize}

\item[（一）] A set of specification that define the purpose of the project．

\item[（二）] Describe the information that we are given（input）and the result that we must output．

\end{itemize}

\item[二．] Analysis

\begin{itemize}

\item[（一）] In this phase，we begin to break the problem down into manageable pieces．

\item[（二）] Two approaches：

\begin{itemize}

\item[1．] Bottom－up

\begin{itemize}

\item[（1）] Older，unstructured strategy．

\item[（2）] Places and early emphasis on the coding fine points．

\item[（3）] Programmer 沒有 master plan for the project．

\item[（4）] 產生的 program has many loosely connected，error－ridden segments．

\end{itemize}

\item[2．] Top－down

\begin{itemize}

\item[（1）] Divide the program into manageable segments．

\end{itemize}

\end{itemize}

\end{itemize}

\item[三．] Design

\begin{itemize}

\item[（一）] 設計者考慮的兩個觀點：

\begin{itemize}

\item[1．] Program 所需要的 data object．

\item[2．] Operations performed on them．

\end{itemize}

\item[（二）] 1．導致 creation of abstract data types．

\begin{itemize}

\item[2．] 導致需要 spec of algorithm and a consideration of algorithm design strategies．

\end{itemize}

\end{itemize}

\item[四．] Refinement and coding

\begin{itemize}

\item[（一）] We choose representations for our data objects and write algorithm for each operation on them．

\item[（二）] 有一點要注意的是：

Data objects 的 representation 能決定 efficiency of the algorithm related to it．

\end{itemize}

共包含了三件事：

\item[（一）] Correctness Proof

\end{itemize}

\end{itemize}
