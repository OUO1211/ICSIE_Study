例 ：AOV Network

圖：AOV —網路，頂點代表課程，邊代表先修關係

定義：一個先後關係若是遞移性的且為非反身性的，則是一個偏序（Partial Order）。

\section*{三．拓樸順序（Topological Order）}

如果給定一個 AOV 網路，則驗證是否恰當即是決定網路中是否存在有向循環。一個不具有向循環的有向圖形稱為一個非循環圖形（Acyclic Graph）。在檢查一個 AOV 網路是否為恰當的演算法執行時，同時會產生一個頂點的線性順序 $v_i 1, v_i 2, v_i 3, \cdots, v_i n$ ，這個順序有下面的性質：如果在網路中 i 是 j 的前導，則在該順序中 i 會排在 j 之前；具有此性質的線性順序，稱為拓樸順序（Topological Order）。在上圖中的網路有二個可能的拓撲順序：
\begin{itemize}
\item[（一）] C1，C13，C4，C8，C14，C15，C5，C2，C3，C10，C7，C11，C12，C6，C9
\item[（二）] C13，C14，C15，C5，C1，C4，C8，C2，C3，C10，C7，C6，C9，C11，C12
\end{itemize}

\section*{四．拓樸排序的演算法}
\begin{itemize}
\item[（一）] 想法
列出一個在網路上沒有前導的頂點，然後把此頂點及所有從該頂點出去的邊刪掉；重複這兩個步驟，直到所有的頂點都已列出，或所有在圖形上的頂點都有前導而無法再做下去時；如果所有圖形上的頂點都有前導，則表 AOV 網路中有循環，亦即該計畫為不恰當的。
\end{itemize}
