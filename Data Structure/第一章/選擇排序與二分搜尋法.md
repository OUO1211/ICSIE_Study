## 定義

- **選擇排序（Selection Sort）**：每一輪從未排序區間中找出最小（或最大）的元素，放到已排序區間的末端，重複直到全部排序完成。
- **二分搜尋法（Binary Search）**：對一個已排序陣列 $list[0] \leq list[1] \leq \cdots \leq list[n-1]$，每次取中間元素與搜尋值 `searchnum` 比較，依比較結果捨棄一半搜尋範圍，逐步縮小區間，直到找到或區間為空。

本章以這兩個演算法作為 [[時間複雜度計算方法FrequencyCount|時間複雜度分析]] 的示範案例；完整的排序/搜尋演算法分類與比較請見資料結構第七章（搜尋與排序）。

## 核心模型/公式

### 選擇排序演算法

```c
void sort(int list[], int n) {
    for (i = 0; i < n; i++) {
        /* 在 list[i] 到 list[n-1] 中找出最小值所在位置 min */
        /* 交換 list[i] 與 list[min] */
    }
}
```

時間複雜度：$O(n^2)$（雙層迴圈）。

### 二分搜尋法：非遞迴版

```c
int binsearch(int list[], int searchnum, int left, int right) {
    /* list[0] <= list[1] <= ... <= list[n-1]，找 searchnum，找到回傳位置，否則回傳 -1 */
    int middle;
    while (left <= right) {
        middle = (left + right) / 2;
        switch (COMPARE(list[middle], searchnum)) {
            case -1: left = middle + 1; break;   /* list[middle] < searchnum */
            case 0:  return middle;               /* 找到 */
            case 1:  right = middle - 1; break;   /* list[middle] > searchnum */
        }
    }
    return -1;
}
```

三種情況判斷：

- $searchnum < list[middle]$：設定 $right = middle - 1$
- $searchnum = list[middle]$：直接回傳 $middle$
- $searchnum > list[middle]$：設定 $left = middle + 1$

### 二分搜尋法：遞迴版

```c
int binsearch(int list[], int searchnum, int left, int right) {
    if (left > right) return -1;
    int middle = (left + right) / 2;
    switch (COMPARE(list[middle], searchnum)) {
        case "<": return binsearch(list, searchnum, middle+1, right);
        case "=": return middle;
        case ">": return binsearch(list, searchnum, left, middle-1);
    }
}
```

時間複雜度：每次搜尋範圍減半，共 $O(\log n)$。此遞迴形式與 [[遞迴時間函數求解法代入法UnrollingMethod]] 中 $T(n) = T(n/2) + 1$ 的模型完全對應。
