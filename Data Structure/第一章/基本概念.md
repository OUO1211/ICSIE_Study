# 第一章：基本概念（Basic Concepts）

本章涵蓋資料結構考科的兩大基礎主軸：**遞迴（Recursion）** 與 **效能分析（Performance Analysis）**，是後續各章演算法分析的共同工具。

## 知識地圖

### 一、遞迴（Recursion）

從遞迴的基本設計原則出發，依序掌握各類經典遞迴範例：

```
遞迴基礎與範例分類
    ├── 數學類：階乘、二項式係數 → Ackermann 函數 → 費氏數列
    ├── 資結類：選擇排序與二分搜尋法（遞迴版）
    └── 其他類：排列組合遞迴生成
```

### 三、效能分析（Performance Analysis）

由「如何量測程式效率」出發，先建立 Space Complexity 概念，再進入 Time Complexity 的計算方法與求解技巧：

```
效能評估
    ├── Space Complexity（固定部分 + 變動部分）
    └── Time Complexity
            ├── Frequency Count（頻率計數 / 直接計數）
            ├── 漸近符號 O / Ω / Θ（描述成長趨勢）
            └── 遞迴時間函數求解
                    ├── 展開代入法 / 猜測驗證法（通用）
                    └── Master Theorem（分治遞迴專用捷徑）
```

- [[效能分析與空間複雜度SpaceComplexity]] — Performance Analysis vs Measurement、遞迴呼叫的空間負擔
- [[時間複雜度計算方法FrequencyCount]] — Frequency Count 表格法、巢狀迴圈直接計數
- [[漸近符號O-Omega-Theta]] — $O$、$\Omega$、$\Theta$ 定義、範例與四大性質
- [[遞迴時間函數求解法代入法UnrollingMethod]] — 展開代入法六種型態 + 猜測驗證法
- [[MasterTheorem主定理]] — 分治遞迴 $T(n)=aT(n/b)+f(n)$ 的三種 case
- [[函數成長率比較GrowthRateComparison]] — 常用恆等式與成長率排序技巧

## 章節重點提示

- 遞迴類考題常要求「畫出遞迴呼叫樹並數呼叫次數」，見 [[階乘與二項式係數遞迴Factorial-Binomial]]。
- Time Complexity 求解優先嘗試 [[MasterTheorem主定理|Master Theorem]]（若 $a,b$ 為常數且 $f(n)$ 可比較），無法套用時才回頭用 [[遞迴時間函數求解法代入法UnrollingMethod|展開代入法]]。
- $\Theta$ 是最精確的漸近符號，見 [[漸近符號O-Omega-Theta]]。
