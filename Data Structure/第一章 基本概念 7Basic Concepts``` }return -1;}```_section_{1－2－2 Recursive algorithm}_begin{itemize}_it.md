\section*{1－2－2 Recursive algorithm}
\begin{itemize}
\item[一．] 種類
\begin{itemize}
\item[（一）] Direct recursion
Def：functions can call themselves
\item[（二）] Indirect recursion
Def：One function may call other functions that invoke the calling function again．形成 calling cycle
\item[（三）] Tail recursion：程式 end 敘述之前，存在一個 recursive call 敘述。
\end{itemize}
\item[二．] Recursion 的優點
\begin{itemize}
\item[（一）] Powerful in expression．Allow us to express a very complex process in very clear term．
\item[（二）] 節省空間，程式較為精簡
\item[（三）] 無須過多的 local 變數及暫存變數
\end{itemize}
\item[三．] 一般人認為寫 Recursion Algorithm 是一種 Mystical Technique，且只針對特殊問題有用。但這是不對的。
Note：
\begin{itemize}
\item[] －＂Any function that we can write using assignment，if－else and while statements can be written recursively．＂
\item[] －遞迴 ↔ 非遞迴 ↔ ：轉換（雙向）
\end{itemize}
\item[四．] 遞迴程式考型與來源種類

\item[（一）] 考型：
\begin{itemize}
\item[1．] Write a recursive algorithm or program．
\item[2．] Given an algorithm or a program，write the execution result and the number of function calls．
\end{itemize}
