第九章 高等樹結構 387
Advanced Tree Structure
\begin{itemize}
\item[（一）] 根部中沒有元素。
\item[（二）] 左子樹為－最小－堆積。
\item[（三）] 右子樹為一最大一堆積。
\item[（四）] 如果右子樹不是空的，那麼假設 i 為左子樹的任一節點，j 為右子樹的相對節點。如果 j 不在存，那麼 j 為右子樹中相對於 i 父親的節點，i 節點中的鍵必小於或等於 j 的鍵。
\end{itemize}

下圖為含有11個元素的雙堆積。最小一堆積的根部為5而最大一堆積為45；最小一中的節點 10 相對於最大一堆積中節點25，而最小－堆積中的節點15相對於最大－堆積中的節點 20 。相對於含有 9 的節點，定義雙堆積特性（四）的節點 j 為最大一堆積中的節點40 。

從雙堆積的定義中，很明顯地看出在 n 個元素的雙堆積（ n＞1）中最小的元素為最小一堆積的根部，而最大的元素為最大一堆積的根部。如果n＝1那麼最小和最大元素相同而且位於最小一堆積的根部中，使用陣列來儲存，設 n 表示陣列中最後被佔據的位置，若 i 為 Min－Heap 中 Node 編號，則相對於最大一堆積的節點為：
$$
\begin{aligned}
& \mathrm{j}=\mathrm{i}+2^{\left\lfloor\log _2 \mathrm{i}\right\rfloor-1} ; \\
& \text { if } \mathrm{j}>\mathrm{n} \text { then } \mathrm{j}:=\mathrm{j} \operatorname{div} 2 ;
\end{aligned}
$$
