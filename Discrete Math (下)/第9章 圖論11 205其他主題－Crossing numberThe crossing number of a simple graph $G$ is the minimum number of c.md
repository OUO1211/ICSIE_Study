其他主題－Crossing number
The crossing number of a simple graph $G$ is the minimum number of crossings that can occur where no three arcs representing edges can cross at the same point．

Note
在判斷 $K_5$ ，$K_{3,3}$ 時，一開始我們把邊扯來扯去想將它平面化，但不論如何做都會至少出現一個（或幾個）交叉的情形，我們就稱 $K_5, K_{3,3}$ 的交叉數都是1。換句話說，若 $G$ 為平面圖，則交叉數為 0 ，但若 $G$ 不為平面圖，我們也希望了解交叉數是多少。
