\section*{生成樹個數－其他計算法－編碼法（Prüfer code）}

以 Prüfer code 為點集合為 $\{1,2, \ldots, n\}$ 的樹造數列的方法：
Step1 纪錄樹上编號最小的葉子所連到的點的编號。
Step2 刪去樹上编號最小的葉子。
Step3重複 Step1，直到此樹只剩下一邊。
由上列步驟可知，所訂出之數列為值可為 $1 \sim n$ 的長度 $n-2$ 的序列，故有 $n^{n-2}$ 種。

將所造之數列 $T: t_1, t_2, \ldots, t_{n-2}$ 還原回樹的方法：
從 $S=\{1,2, \ldots, n\}$ 中選出沒有出現在 $T$ 中且為最小的數（設為 $s_1$ ），將點 $s_1$ 與點 $t_1$ 相連；從 $S-\left\{s_1\right\}$ 中選出没有出現在 $T-\left\{t_1\right\}$ 中且為最小的數（設為 $s_2$ ），將點 $s_2$ 與點 $t_2$ 相連；從 $S-\left\{s_1, s_2\right\}$ 中選出没有出現在 $T-\left\{t_1, t_2\right\}$ 中且為最小的数（設為 $s_3$ ），將點 $s_3$ 與點 $t_3$ 相連；⋮
直到 $S-\left\{s_1, s_2, \ldots, s_{n-2}\right\}$ 恰剩下兩數，把此兩數所代表的點相連即可。
Note
\begin{itemize}
\item[（1）] 由上述還原法知 Prüfer code 為一種 1—1 且 onto 的對應方式，故知點集合為 $\{1,2, \ldots, n\}$ 的樹共有 $n^{n-2}$ 個。
\item[（2）] 所造之數列 $T$ 中未曾出現的數字必是葉子的編號。
\item[（3）] 所造之數列 $T$ 中曾出現的數字其度數（degree）必＝出現的次數＋1。
\end{itemize}
