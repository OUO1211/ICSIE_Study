鋅對稱矩陣的性質
令 $A$ 為 $n$ 階實斜對稱矩陣，則
（1）$A$ 為正規矩陣。
（2）$A$ 的相異特徵根所對的特徵向量必正交．
（3）$A$ 的特徵根都是 0 或純虚数。
【93高雄統計、94台大数學、95彰師数學】
（4） $\operatorname{det}(A)= \begin{cases}\text { 實数，當 } n \text { 為偶数 } \\ 0, & \text { 當 } n \text { 為奇数 }\end{cases}$
【92北科資工、93高雄統計、95彰師数學、97政大應数】
【證明】
（1）$A^H A=A^T A=-A A, A A^H=A A^T=-A A$ ，故 $A$ 為正規．
（2）由正規可得，或另證如下：
∵ 設 $A \boldsymbol{x}=\lambda_1 \boldsymbol{x}, A \boldsymbol{y}=\lambda_2 \boldsymbol{y}, \boldsymbol{x}, \boldsymbol{y} \neq \mathbf{0}$ ，故
$$
\begin{aligned}
& \lambda_1\langle\boldsymbol{x}, \boldsymbol{y}\rangle=\left\langle\lambda_1 \boldsymbol{x}, \boldsymbol{y}\right\rangle=\langle A \boldsymbol{x}, \boldsymbol{y}\rangle=\left\langle\boldsymbol{x}, A^T \boldsymbol{y}\right\rangle=\left\langle\boldsymbol{x}, \lambda_2 \boldsymbol{y}\right\rangle=\overline{\lambda_2}\langle\boldsymbol{x}, \boldsymbol{y}\rangle, \\
& \therefore \lambda_1\langle\boldsymbol{x}, \boldsymbol{y}\rangle-\overline{\lambda_2}\langle\boldsymbol{x}, \boldsymbol{y}\rangle=0, \\
& \left.\therefore\left(\lambda_1-\overline{\lambda_2}\right)<\boldsymbol{x}, \boldsymbol{y}\right\rangle=0,
\end{aligned}
$$
∵ 由（3）可得斜對稱矩陣的特徵根必為 0 或純虛數且 $\lambda_1 \neq \lambda_2, \therefore \lambda_1 \neq \overline{\lambda_2}$ ，
$\therefore\langle\boldsymbol{x}, \boldsymbol{y}\rangle=0$ ，即 $\boldsymbol{x} \perp \boldsymbol{y}$ ．
（3）～（4）$\because A^T=-A$ ，且 $A \in R^{n \times n}, \therefore A^H=-A$ ，即 $A$ 為 skew－Hermitian，故由前面結果得證．
